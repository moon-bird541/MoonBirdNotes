# 固定编辑器工具栏

## Goal

为笔记和日记编辑器提供一种常驻在编辑区域上方的固定工具栏模式，
让用户无需先选中文字也能快速找到格式与插入操作；同时保留现有工具栏
交互，并允许用户在设置中切换两种模式。

## Background

- 用户提供的参考图是一条横向单行工具栏，包含文字样式、标题/列表/引用、
  分隔线、链接、图片、附件、表情、表格、代码/公式等分组操作，以及右侧
  的预览、置顶、全屏和完成入口。
- 固定工具栏只需要在“编辑笔记”和“编辑日记”时显示。
- 本任务必须复用 MoonBirdNotes 已有编辑器命令和设置持久化方式，不应另建
  一套与现有格式状态脱节的编辑器。
- 参考图用于表达布局和交互方向，不代表图中的每个按钮都已确定纳入首版。
- 当前笔记编辑器在选中文字后显示 `FloatingFormatToolbar.vue`，提供粗体、
  斜体、删除线、行内代码、H1-H3、引用、代码块、分隔线及表格单元格对齐；
  图片和表格插入位于右侧 `SideTableToolbar.vue`。
- 当前日记编辑器也使用选区浮动工具栏，但实现仍内嵌在
  `DiaryEditView.vue`，提供 H1-H3、粗体、斜体、删除线、引用、分隔线、
  表格和图片。
- 两个编辑器都把 Toast UI 原生工具栏配置为 `toolbarItems: []`，因此固定
  工具栏应成为项目自己的共享组件，而不是同时恢复第三方默认工具栏。
- `editorSettings.js` 已统一负责偏好规范化、localStorage 持久化和变更事件；
  两个编辑页都实时监听该事件，因此工具栏模式可即时切换，无需刷新。

## Requirements

1. 笔记编辑页与日记编辑页支持顶部固定工具栏模式。
2. 设置面板提供“固定工具栏”和“当前工具栏模式”的切换选项，并持久化为
   统一编辑器偏好，使两个编辑页保持一致。
3. 切换模式后立即在已打开的编辑页生效，不需要刷新或重新登录。
4. 固定模式应复用现有格式、表格、图片等命令，保留键盘输入、选区、自动
   保存与 Markdown 内容行为。
5. 不改变后端笔记/日记接口与持久化格式。
6. 两种工具栏模式互斥：
   - 固定模式隐藏选区浮动格式栏及独立图片/表格入口，把首版能力统一收进
     顶部工具栏；
   - 现有模式完整保留当前选区浮动栏与独立插入控件的行为和布局。
7. 固定工具栏首版包含：H1-H3、粗体、斜体、删除线、行内代码、引用、
   无序/有序/任务列表、分隔线、链接、图片、表格和代码块。
8. 固定工具栏应根据当前光标或选区同步可用状态与激活状态；需要输入额外
   数据的链接、图片和表格使用清晰的弹层/选择器完成。
9. 固定工具栏位于笔记/日记正文编辑卡片的标题下方，并使用 sticky 吸附：
    长内容滚动时始终停留在可视区域顶部，但不覆盖页面导航或正文。
10. 桌面端保持单行分组布局；窄屏和高缩放场景允许工具栏自身横向滚动，
    不换成遮挡正文的多行浮层，也不产生页面级横向滚动。
11. 兼容已有用户：未保存该偏好或存储值无效时默认使用现有工具栏模式。
12. 固定工具栏按钮在编辑器未就绪时显示禁用状态；图标按钮具备中文提示和
    可访问名称，键盘焦点可见。

## Out of Scope

- 首版不实现下划线、文字颜色、背景高亮、清除格式、附件、表情、公式、
  书签、置顶、全屏或“完成”等参考图扩展按钮。
- 因参考图存在而新增后端格式或上传契约。
- 重写 Toast UI Editor 或更换编辑器框架。
- 将固定工具栏显示到详情页、列表页或知识对话页。

## Acceptance Criteria

- [x] 用户可在设置中选择固定工具栏或现有工具栏模式，刷新后选择仍保留。
- [x] 固定模式下，笔记和日记编辑页的编辑区域上方显示一条稳定的工具栏。
- [x] 现有模式下，当前工具栏行为与布局不回归。
- [x] 固定工具栏中的首版操作能正确作用于光标或选区，并同步激活状态。
- [x] 链接弹层能预填当前选中文字；无选区时要求链接文字和 URL，提交后在
  原光标位置插入链接。
- [x] 图片沿用现有上传校验/接口，表格沿用现有行列上限和选择器。
- [x] 两种模式都不破坏输入法、自动保存、Markdown、表格/图片与选区格式化。
- [x] 桌面、窄屏和浏览器缩放下可访问全部首版操作，不遮挡正文。
- [x] 无偏好、旧偏好对象或非法模式值均回退到现有工具栏模式。
- [x] 前端构建及笔记/日记编辑器相关浏览器回归通过。
