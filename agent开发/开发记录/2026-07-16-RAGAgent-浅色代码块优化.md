# RAGAgent 浅色代码块优化

日期：2026-07-16

## 做了什么

- 将 Agent 回答中的代码块从深黑蓝背景改为柔和的浅灰米色背景。
- 工具栏使用比代码正文略深的米灰色，通过细分隔线建立层级。
- 代码文字改为深灰蓝色，保持可读性但避免强烈黑白反差。
- “复制代码”按钮改用系统苔绿色，悬停时变为正文深蓝色。
- 边框改为低透明度暖灰色，阴影缩小并降低透明度。
- 保留代码块圆角、语言名称、横向滚动和复制功能。

## 为什么这样做

页面整体以米白、暖灰和低饱和绿色为主。原来的深色代码块面积较大，在长接口回答中会形成多个接近黑色的视觉断层，抢占正文注意力。

浅色代码区仍然能通过边框、工具栏和等宽字体与正文区分，但会更自然地融入现有页面色彩体系，也更接近浅色模式下连续阅读的体验。

## 验证

- Vite 生产构建通过。
- 共转换 1747 个模块，无 CSS 或 Vue 编译错误。
- 未修改代码复制逻辑、Markdown 安全净化或 Agent 后端行为。
