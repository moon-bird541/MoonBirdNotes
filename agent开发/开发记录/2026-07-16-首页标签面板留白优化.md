# 首页标签面板留白优化

日期：2026-07-16

## 问题原因

首页四个主面板对齐后，“标签分布”会与右侧“最近 5 篇”保持同高。但标签面板内部仍然采用普通文档流，标题、三条标签和按钮全部堆在顶部，剩余空间集中在按钮下方，形成大面积无意义留白。

## 做了什么

- 标签面板改为三行 Grid：标题、数据区、底部操作。
- 标签数据区使用 `minmax(0, 1fr)` 占据中间剩余空间。
- 三条标签在数据区垂直居中，并增加均匀间距。
- “查看全部标签”固定在面板底部。
- 缩短按钮与数据区的额外上边距。
- 980px 以下单列布局恢复自然高度和紧凑标签间距，避免移动端被不必要拉高。

## 为什么这样做

四个面板继续保持对齐，但空白应该被用于建立内容节奏，而不是集中在某一处。三段式布局能让标题、数据和操作分别占据稳定位置，数据数量变化时也不会破坏面板结构。

## 验证

- Vite 生产构建通过。
- 共转换 1747 个模块，无 Vue 或 CSS 编译错误。
- 未修改标签统计数据和跳转逻辑。
