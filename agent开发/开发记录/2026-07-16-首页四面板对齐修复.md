# 首页四面板对齐修复

日期：2026-07-16

## 问题原因

首页四个主面板已经位于两列两行的 CSS Grid 中，但基础样式设置了：

```css
align-items: start;
```

因此每个面板只使用自身内容高度。同一行中的“桌面数字”和“上传热力图”高度不同，“标签分布”和“最近 5 篇”高度也不同，导致左右边线无法对齐。

## 做了什么

- 首页主网格覆盖为 `align-items: stretch`。
- 四个主面板统一使用 `height: 100%`，填满各自所在网格单元。
- 顶部两个面板保持同高。
- 底部两个面板保持同高。
- 左侧两块保持统一列宽，右侧两块保持统一列宽。
- 保留 980px 以下原有单列响应式布局。

## 为什么这样做

面板高度应该由同一网格行中内容最多的面板决定，而不是手工写死像素高度。使用 Grid 原生拉伸可以在统计数据、标签数量或最近笔记内容变化时继续保持对齐。

## 验证

- Vite 生产构建通过。
- 共转换 1747 个模块，无 Vue 或 CSS 编译错误。
- 未修改首页数据接口和交互逻辑。
