# RAGAgent：全量笔记首次向量化

日期：2026-07-14

## 本次做了什么

在用户明确要求“把这些笔记上传”后，执行了：

```text
python manage.py rebuild_rag_index
```

该命令读取 MySQL 中所有 Note，并按既有安全边界处理：

- `ai_indexing_enabled=true` 且未软删除的 Note：分割父片段和子片段，将子片段向量文本发送到硅基流动 `BAAI/bge-m3`，再把返回的 1024 维 Dense 向量写入 Qdrant。
- 已软删除的 Note：不发送到硅基流动，并清理可能残留的派生索引。
- Note 原文：只读，不做修改。

本次没有修改业务代码，因此没有新增代码注释；只产生了可从 MySQL 原文重建的 RAG 派生数据。

## 为什么这样做

上一项工作只把现有及新建 Note 的 `ai_indexing_enabled` 默认策略调整为允许，并没有实际上传正文或生成向量。本次收到用户明确上传授权后，才执行全量重建，让现有笔记能够用于后续语义检索。
