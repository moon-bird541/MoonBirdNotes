# RAGAgent GPT 风格回答排版

日期：2026-07-16

## 为什么再次调整

上一版虽然改善了字号和代码块，但整体仍然是“技术文档卡片”风格：回答有明显容器、标题有装饰竖线、代码块视觉重量较大，和 GPT 网页端的连续内容流差异明显。

本次目标不是继续增加装饰，而是减少界面元素，让回答内容本身成为视觉主体。

## 做了什么

- 移除 Agent 回答容器的背景、边框、圆角和阴影。
- 用户消息仍保留气泡，Agent 回答改为干净的连续正文流。
- 回答正文最大宽度调整为 780px，接近常见对话产品的阅读宽度。
- 移除章节标题前的金色竖线。
- 完全隐藏历史回答中的水平分隔线。
- 标题使用纯文字层级，不再使用额外装饰。
- 列表项间距压缩，列表内段落不再产生额外下边距。
- Markdown 配置关闭 `breaks`，普通换行不再被强制转换为 `<br>`，减少模型换行导致的松散排版。
- 代码块增加独立顶部工具栏：
  - 显示语言名称；
  - 提供“复制代码”按钮；
  - 复制成功后短暂显示“已复制”；
  - 复制内容直接读取 `code.textContent`，不写入 HTML 属性。
- 代码工具栏在 Markdown 完成 DOMPurify 净化后，以固定安全模板添加，保持不可信回答的安全边界。

## 为什么这样实现

GPT 风格的核心不是更多视觉组件，而是稳定阅读宽度、清晰标题层级、克制的列表间距以及代码块与正文之间明确但不过度的区分。

关闭 Markdown 的强制换行尤其重要。模型输出中经常包含为了可读性插入的换行，如果全部转换成 `<br>`，浏览器会产生大量不必要的纵向空白。
