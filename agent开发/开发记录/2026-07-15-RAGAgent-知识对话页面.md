# RAGAgent 知识对话页面

日期：2026-07-15

## 做了什么

1. 新增 Vue 页面 `KnowledgeChatView.vue`。
2. 新增 `/knowledge-chat` 路由，并沿用现有登录态路由守卫。
3. 在工作区侧边栏增加“知识对话”入口。
4. 对接现有只读接口：

```text
POST /api/agent/knowledge/chat/
```

5. 页面支持：
   - 输入问题并发送；
   - Enter 发送、Shift + Enter 换行；
   - Agent 检索等待状态；
   - 用户消息和 Agent 回答轨迹；
   - 资料不足提示；
   - 引用来源标题和章节路径；
   - 点击来源进入对应笔记详情；
   - 新建当前页面内的空对话；
   - 限流、超时和通用错误提示；
   - 桌面端与移动端响应式布局；
   - 减少动态效果系统偏好支持。
6. 对话 API 单独使用 95 秒前端超时，覆盖 Knowledge Agent 后端 90 秒执行上限，不修改其他 API 的通用超时。

## 为什么这样做

- Knowledge Agent 已经完成后端能力，但此前没有用户可以直接使用的前端入口。
- 页面复用 `WorkspaceShell`、现有路由鉴权和 Axios CSRF/JWT 刷新机制，避免建立第二套认证或导航。
- 当前后端没有长期会话记忆，因此前端只维护本页面生命周期内的消息轨迹，不向用户暗示已经保存长期对话。
- 来源使用普通列表而不是卡片墙，便于快速核对标题和章节，同时保持现有 MoonBirdNotes 的安静纸张风格。
- 回答以纯文本展示，避免未经额外净化就渲染模型生成的 HTML。

执行：

```powershell
cd frontend/moonsbirdnotrs_vue
npm run build
```

结果：Vite 生产构建成功，新增对话页面被正确拆分为独立资源。

## 安全边界

- 页面只调用现有 Knowledge Agent 只读接口。
- 没有增加创建、修改、删除笔记或修改设置的入口。
- API Key 不进入前端代码。
- 来源跳转只使用服务器返回的 `note_id`。
