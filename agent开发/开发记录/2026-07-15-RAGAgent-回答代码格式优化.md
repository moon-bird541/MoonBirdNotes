# RAGAgent 回答代码格式优化

日期：2026-07-15

## 做了什么

1. 为 Agent 回答增加安全 Markdown 渲染。
2. 新增独立工具模块：

```text
frontend/moonsbirdnotrs_vue/src/utils/renderAgentAnswer.js
```

3. 使用 `marked` 将 Markdown 转换为 HTML。
4. 使用 `DOMPurify` 净化转换后的 HTML，再交给 Vue `v-html`。
5. 增加以下排版样式：
   - 行内代码；
   - JSON 和代码围栏；
   - 可横向滚动的长代码；
   - 列表；
   - 引用；
   - 链接；
   - 正文段落间距。
6. 更新 Knowledge Agent Prompt：
   - 接口路径和短字段使用行内代码；
   - JSON、请求体、响应体和代码使用带语言标记的围栏代码块；
   - Agent 最外层响应仍保持严格 JSON。

## 为什么这样做

此前回答使用纯文本渲染，请求体和响应体 JSON 会与普通中文正文挤在同一段中，无法保持缩进，也不便于复制和核对。

渲染逻辑拆分到独立工具文件，避免 Markdown 解析、安全净化和对话页面状态混在一个 Vue 文件中。

## 安全处理

- Agent 回答按不可信文本处理。
- Markdown 转换后必须通过 DOMPurify。
- 禁止 `script`、`style`、`iframe`、`object`、`embed` 和 `form`。
- 禁止内联事件和内联样式属性。
- 用户消息仍使用 Vue 文本插值，不使用 HTML 渲染。
